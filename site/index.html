Questions.

Does Fokly record my screen?

No. Every few seconds it looks at the window in front of you, reads it in memory and lets it go. Screenshots and screen text are never stored. History keeps only your goals, times and short notes like “Watching the Blue Angels”, on your Mac.

Is anything sent to the cloud?

No. The AI model runs inside Fokly on your Mac. The only time Fokly uses the internet is to download the model once. After that it works offline.

Which Macs does it run on?

Any Mac with Apple silicon and macOS 26 or later. With the Light model it uses about 2 GB of memory while you focus, and gives it back during breaks.

What if it gets it wrong?

Click “This is relevant” and Fokly won't ask about it again for the rest of the session. You can also list things that always count, and things that never do.

Why does it need Screen Recording and Accessibility?

Screen Recording lets it see the window you're working in. Accessibility lets “Take me back” return you to the exact window and browser tab. The first launch walks you through both.

Does it cost anything?

No. Fokly is free and open source, under the MIT license. The code is on GitHub.
